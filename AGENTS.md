# AGENTS.md

## Code Style Guidelines

- Use modern, SOTA tech stacks.
- Write concise and straightforward code. Do not hack to the solution when possible.
- Use default parameters, settings, functions, libraries, and frameworks whenever possible. Do not specify unnecessary parameters or settings. Focus on implementing the core logic instead of defensive programming.
- Do not implement features that are not required. Ask me when you are unsure about the requirements or you think there is a better way to implement something.
